# AI Application Engineering Roadmap

A 36–42 week self-study plan, from neural-network foundations to a production AI capstone. Tick the boxes in each phase file as you go (edit the file on GitHub and change `[ ]` to `[x]`).

- **Target duration:** 36–42 weeks
- **Weekly commitment:** 8–10 hours
- **Budget:** Free learning materials; optional compute costs only
- **Learning style:** Recorded lectures + hands-on coding + assignments + one final capstone

The time estimates below account for your preferred slower learning pace: best case assumes you understand a topic relatively quickly; worst case allows extra pausing, note-taking, debugging and rework. They are planning estimates, not course-published completion times.

## 0. How to use this checklist

- Create a OneNote page called AI Application Engineering Roadmap.
- Create one section per phase below.
- Watch the selected videos only. Avoid the skipped lectures unless you later identify a knowledge gap.
- Keep code in a separate GitHub repository.
- Complete the practical task before moving to the next phase.
- Maintain a short notes page for every topic: What it is, why it matters, how it works, when to use it, common failure modes.

### Time estimate convention

- Best case: you understand the material quickly and complete the coding exercises with limited rework.
- Worst case: you pause frequently, revisit concepts, debug independently and repeat exercises.
- These estimates include the video-watching allowance you requested (roughly twice the actual video duration), plus practical work.

## Weekly study routine

At 8–10 hours per week, use this as a default schedule:

- 3–4 hours: watch lectures and take notes.
- 3–4 hours: code and complete assignments.
- 1 hour: revise concepts and explain them in your own words.
- 1 hour: experiment with AI tools and apply what you learned.

If you have only 5 hours in a particular week, do not rush through the lectures. Continue the same phase into the following week.

## Final skill checklist

At the end of this roadmap, you should be able to tick off these capabilities:

- [ ] Explain how neural networks and LLMs work internally.
- [ ] Understand Transformer architecture, tokenization and attention.
- [ ] Understand LLM training, inference, evaluation and alignment.
- [ ] Build applications using LLM APIs.
- [ ] Build RAG applications with vector search.
- [ ] Design tool-using agents and multi-step workflows.
- [ ] Implement agent memory and planning.
- [ ] Evaluate model outputs and agent behaviour.
- [ ] Deploy and monitor LLM applications.
- [ ] Understand production risks, security and reliability.
- [ ] Build and publish a complete AI application.

One important rule: Don't add more courses while following this roadmap. Finish the selected lectures and assignments first. The purpose of this curriculum is to develop implementation ability, not accumulate course completion badges.
