This is a free, practical course covering RAG, vector search, orchestration, evaluation and monitoring. It treats LLMs as black boxes, which makes it complementary to Stanford CS336. [Course overview and curriculum](https://datatalksclub.github.io/docs/courses/llm-zoomcamp/).

## 5.1 Agentic RAG

- [ ] Complete Module 1 — Agentic RAG.
- [ ] Understand what Retrieval-Augmented Generation (RAG) is.
- [ ] Build a simple FAQ-based RAG application.
- [ ] Understand document ingestion and retrieval.
- [ ] Understand prompt construction.
- [ ] Implement function calling.
- [ ] Build a basic agent loop.
- [ ] Complete Homework 1.

## 5.2 Vector search and embeddings

- [ ] Complete Module 2 — Vector Search.
- [ ] Understand embeddings.
- [ ] Understand semantic search.
- [ ] Understand similarity measures.
- [ ] Understand vector databases and indexing.
- [ ] Experiment with SQLite-based search.
- [ ] Experiment with PostgreSQL/PGVector.
- [ ] Compare keyword search with semantic search.
- [ ] Complete Homework 2.

## 5.3 Orchestration

- [ ] Complete Module 3 — Orchestration.
- [ ] Understand workflow orchestration.
- [ ] Understand context engineering.
- [ ] Understand the difference between a workflow and an autonomous agent.
- [ ] Build a multi-step LLM workflow.
- [ ] Understand how to manage state between steps.
- [ ] Complete Homework 3.

## 5.4 Evaluation

- [ ] Complete Module 4 — Evaluation.
- [ ] Understand how to create a ground-truth dataset.
- [ ] Understand hit rate and MRR.
- [ ] Evaluate retrieval quality.
- [ ] Evaluate answer quality.
- [ ] Understand LLM-as-a-judge.
- [ ] Evaluate agent tool-call trajectories.
- [ ] Complete Homework 4.

## 5.5 Monitoring

- [ ] Complete Module 5 — Monitoring.
- [ ] Track latency.
- [ ] Track token usage and cost.
- [ ] Track application errors.
- [ ] Capture user feedback.
- [ ] Understand dashboards and monitoring with Grafana.
- [ ] Understand the role of PostgreSQL and Streamlit.
- [ ] Complete Homework 5.

## 5.6 Capstone

- [ ] Review the official LLM Zoomcamp capstone guidelines.
- [ ] Build a RAG application using your own knowledge base.
- [ ] Implement retrieval and answer generation.
- [ ] Implement an evaluation pipeline.
- [ ] Build a simple user interface.
- [ ] Add monitoring and feedback.
- [ ] Document known limitations and failure cases.

### Optional material — do not prioritize yet

- [ ] Module 7 — End-to-end project example.
