# Phase 3 — Understand AI agents and agent architecture

[← Back to roadmap](README.md)

_Sub-chapter times in [brackets] are realistic mid-point estimates (between best and worst case), including ~2× video time plus exercises._

Estimated: 18–25 hours | 2–3 weeks

Primary resource: UC Berkeley — Agentic AI, Fall 2025

### Link

- [Official course website and lecture recordings](https://rdi.berkeley.edu/agentic-ai/f25)

The course covers agent foundations, reasoning, planning, infrastructure, applications and limitations. Select only the lectures below to avoid repeating the Transformer and training material from Stanford. [Official syllabus](https://rdi.berkeley.edu/agentic-ai/f25).

## 3.1 Agent fundamentals [4 h]

- [ ] Lecture 2 — LLM Agents Overview, Yann Dubois.
- [ ] Understand the difference between a chatbot and an agent.
- [ ] Understand the agent loop: observe, reason, act and observe again.
- [ ] Understand tools, function calling and external actions.

## 3.2 Agent architecture [4.5 h]

- [ ] Lecture 3 — Evolution of System Designs from an AI Engineer Perspective.
- [ ] Understand the components of an agent system.
- [ ] Understand how the model, tools, memory and orchestration layer interact.
- [ ] Draw an architecture diagram for a simple agent application.

## 3.3 Agent evaluation [5 h]

- [ ] Lecture 5 — Agent Evaluation and Project Overview.
- [ ] Understand how to evaluate an agent beyond whether its final answer looks correct.
- [ ] Understand task success, tool-call accuracy and execution trajectories.
- [ ] Identify failure cases and build a small evaluation dataset.

## 3.4 Multi-agent systems [3 h]

- [ ] Lecture 7 — Multi-Agent AI, Noam Brown.
- [ ] Understand when multiple agents can be useful.
- [ ] Understand coordination, delegation and communication.
- [ ] Identify situations where a single agent is simpler and more reliable.

## 3.5 Production lessons [3 h]

- [ ] Lecture 10 — Practical Lessons from Deploying Real-World AI Agents.
- [ ] Note the common engineering problems that arise outside demos.
- [ ] Identify reliability and operational challenges.

### Phase completion test

- [ ] I can design a basic tool-using AI agent.
- [ ] I can explain when to use a single-agent or multi-agent architecture.
- [ ] I understand how to evaluate an agent's actions, not just its final response.
